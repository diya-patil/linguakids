# LinguaKids

A multilingual Progressive Web App (PWA) that helps children learn languages through lessons, games and progress tracking.

**Live demo:** https://linguakids-16043.web.app

## Features
- Language selection with English, Hindi, Marathi, German and Chinese
- Levels, games and study pages for each language
- Progress tracking for students
- Student and teacher login
- Works offline and can be installed like an app (PWA)

## Technologies used
HTML, CSS, JavaScript, Firebase (database and hosting), Service Workers

## Note
The admin and teacher portal pages are not included in this repository because they contain private login details.
